REAL GEODATA + CAPTURED ASSETS → ALIGNED SCENE → RENDERING

用真实数据，构建真实地点的三维场景

高程给出山体起伏，点云补充空间结构，影像提供地表外观，已有 3DGS 表现局部实拍场景。Forge3D 把对齐后的数据放进共同的渲染系统，让地形、树木与建筑参与同一套遮挡、光照和阴影计算。

核心价值数据是什么两条输入路线融合渲染原理用途与扩展获取与全球覆盖边界与验证官方来源
01

核心价值：从有依据的数据，到可观察的场景

它给我们的路径是：选一个真实地点，收集相应的地理资料或实拍重建资产，再把它们组合成可从不同角度展示的三维场景。

Forge3D 的定位是 Python 控制的地形与地理可视化工具，底层使用 Rust 和 WebGPU。它能读取高程与其他空间数据，设置相机和环境，生成静态图、地图或镜头序列。它承担渲染环节；照片重建、数据采集和精度验收需要相应的上游工具与流程。

截图中的 1.41.0 更新重点，是把 DEM 地形、COPC LiDAR 点云和已有三维高斯放进统一的路径追踪流程，让山脊遮挡树木、树木向地面投影。这种统一计算是场景真实感的关键。

真实数据提供的是位置、形态和外观依据。渲染的太阳、天空、雾效与镜头可以另行设置，因此输出画面不一定对应某一时刻现场实际看到的景象。

真实地点DEM 地形COPC 点云已有 3DGS统一遮挡与阴影Python 批处理

02

四类输入，分别回答不同问题

手机上可左右滑动表格。

山谷场景中的数据分工；是否同时具备这些输入，取决于当地数据和项目目标。
输入它是什么怎样获得能提供什么
高程 DEM
每个位置有多高		将区域划成网格，每个格点存一个高度。裸地模型 DTM 描述地面；表面模型 DSM 可包含树冠、屋顶。卫星雷达、立体摄影、航空激光测量；点云经地面分类与插值也能生成高程栅格。常见文件是 GeoTIFF。山脉、坡面和谷底的整体形状。单一高度场无法完整表达洞穴、悬挑或同一位置的多层结构。
点云
空间中有哪些点		大量带 X、Y、Z 坐标的采样点，可附分类、回波、强度或颜色。它本身没有连续表面，颜色也不一定自带。飞机、无人机、车载或地面 LiDAR；多视图摄影也可计算点云。常见格式为 LAS / LAZ，COPC 是便于分区读取的 LAZ 组织方式。地面、树冠、屋顶等空间结构。只有采集视角实际看见或测到的部分有数据，密度与遮挡会影响细节。
地理影像
表面是什么样		带地理位置的像素。正射影像经过几何纠正，可与地图对齐；卫星、航空影像的分辨率差别很大。卫星拍摄、有人机航拍或无人机摄影，经过纠正与拼接。地形着色通常需裁剪并重采样到对应网格。颜色与纹理，例如草地、道路和屋顶外观。俯视照片不会自动变成建筑立面或实体几何。
已有 3DGS
局部实拍的三维外观		一组带位置、尺度、方向、透明度与颜色参数的三维高斯。即使同为 .ply 文件，普通点云与训练好的高斯资产也不是同一种数据。用外部工具对多视角照片及相机信息优化，导出兼容资产，再定位到地理场景。并非把一张航拍图交给 Forge3D 就能自动生成。补充重点区域的实拍外观，供新视角展示。高斯拟合的视觉效果不自动等于可测量的完整表面。

“30 米高程”与“10 厘米影像”描述不同事情。前者主要是高度网格的采样间距，后者是影像像素对应的地面尺寸。贴上清晰照片可以让场景看起来细致，但不会把粗糙地形变成同等精度的几何。

03

两条输入路线，可以在同一个场景汇合

ROUTE A / 公共资料

先从开放的地理数据开始

  1. 确定区域，查找对应高程、点云和正射影像。
  2. 记录测量年份、坐标与高程基准、分辨率和许可。
  3. 只下载需要的瓦片，裁剪、分类、整理格式。
  4. 将影像与地形配准，再按需加入点云或已有高斯。

适合先获得山谷、山体或城市区域的大范围背景。不是每个地点都具有公开的高密度点云与高清航片。

ROUTE B / 无人机实拍

对重点区域补充自己的采集

  1. 用有重叠的多角度照片覆盖目标区域；立面通常还需斜拍。
  2. 在外部摄影测量工具中求解相机与空间关系。
  3. 按需求生成点云、DSM、正射影像；另用兼容工具重建 3DGS。
  4. 用测量控制或可靠参考检查尺度、位置和高程，再导入渲染。

普通相机无人机取得的是照片；搭载激光设备才能直接采集 LiDAR。摄影测量点云也是计算得到的三维结果。

公共地形作背景 + 实拍重建补重点区域
裁剪与整理 → 坐标、尺度、高程对齐 → Forge3D 融合渲染 → 图片 / 多视角序列 / 漫游视频

对齐是汇合的前提。经纬度与以米为单位的局部坐标不能直接相加；摄影重建还可能只有相对尺度。水平坐标、高程基准、单位、轴方向和局部原点都要一致，否则会出现悬空、错位或大小不对。

OpenDroneMap 官方文档 ↗介绍从航空照片生成地理资产的外部流程；Forge3D 融合文档 ↗说明已有高斯的变换与定位。两条路线的组合是本研究提出的使用流程，尚未本机验证。

04

原理：不同表示，共同参与光线计算

  1. 准备不同形式的空间资产

    DEM 保留为高度场，点云提供离散采样，高斯保留外观与空间参数。影像在地形上提供颜色。它们不必先全部转换成同一种网格。

    前提：位置和尺度已经对齐

  2. 建立统一的空间查询

    融合路径把地形、点云与高斯加入共同的加速结构。相机光线查询场景，阴影光线也查询这些对象，判断光能到达哪里、被哪些对象遮挡。

    结果：山体与局部对象相互遮挡

  3. 计算光照、阴影和雾效

    路径追踪根据表面属性与环境计算画面，融合流程使用 ReSTIR 进行光照采样。太阳、天空、高度雾和地形配色共同形成展示效果。

    重点：同一套场景中的相互作用

  4. 分块、分页并输出视图

    输出可分块处理来控制像素缓冲占用，场景资产可按需载入驻留池。连续改变相机生成一组帧，再由视频工具合成镜头序列。

    输出：静态帧与多视角序列

官方说明包含地形配色、平滑法线、LiDAR 表面片元、分页与多视角渲染等选项。交互地形查看器、批处理和融合路径各有自己的使用条件；支持一种输出能力并不代表所有模式都具有相同速度或许可。

05

用途，以及我们可以继续扩展的方向

LANDSCAPE / 景观表达

真实地点的图像与漫游

展示山谷、地形和重点建筑，设置镜头路线、日照与雾效，制作空间介绍、旅游讲解和景观视频。

MAP / 地理信息表达

把二维资料放回空间

在真实起伏上表达道路、地表分类或主题数据。重点是更清楚地呈现空间关系；地图注记等功能须核对具体模式与许可。

REUSE / 地理资产复用

大范围背景与局部实拍结合

公共地形和影像可以反复使用，自己的无人机重建补充重点区域，形成可更新、可生成不同视角的展示资产。

后续可做：业务标注、时间对比与交互展示

可以设计兴趣点、图层开关、镜头书签与解释面板；采集同一区域不同年份的数据，可以进一步做变化对比。把地理背景与实拍资产组合，也有机会成为数字场景的基础。

这些是扩展方向，尚不是本档案完成的功能。导航、碰撞、实时网页展示、变化检测和业务计算需要额外开发。洪水、滑坡、日照评估等分析还要接入相应算法与验证，画面的光照效果不能替代专业计算结果。

06

如何取得数据，是否已经覆盖全世界

全球已有公开的基础地形与卫星影像；精细到树木、屋顶和立面的数据，覆盖与开放程度仍不均匀。

对截图中的瑞士山谷，我们可以从官方开放产品获取自己的源数据。尚未确认作者公开了视频所用的全部裁剪文件、处理脚本与场景参数，因此“能用相同类别的公共数据”与“拿到作者的完整项目”需要区分。

手机上可左右滑动表格。

建议先按地点与目标细节查覆盖，再选择产品；不要把基础全球覆盖理解为全球精细三维扫描。
数据入口提供什么覆盖与使用方式
瑞士 swisstoposwissALTI3D 高程、swissSURFACE3D 分类点云、SWISSIMAGE 正射影像。在官方产品页选择区域与瓦片，查看日期和数据属性后下载。正式开放产品允许加工与商用，按条款标注来源；样例和特殊服务另查适用条件。
Copernicus DEM全球陆地的 GLO-30 / GLO-90，标称约 30 / 90 米网格。官方产品与获取说明。免费许可且有来源标注义务；它是包含植被及建筑表面的 DSM，适合基础地形背景。
卫星地理影像例如 Sentinel-2 的部分波段为 10 米分辨率，可用于大范围地表颜色与分类。Sentinel-2 官方说明。有全球性陆地观测，但单景受云与日期影响；10 米像素无法提供航空照片级屋顶细节。
区域航空 LiDAR例如美国 USGS 3DEP 的分类点云与高程产品。USGS 免费产品入口。其他国家、地区各有政策；须按具体地点查覆盖、点密度、年份和许可。
卫星激光观测GEDI 等提供沿轨足迹里的地面高度与植被结构观测。GEDI 官方采样说明。属于轨道采样，不是连续覆盖的航空点云，不能直接当作全球逐棵树、逐栋建筑的精细三维资产。

免费获取不意味着所有来源具有同一许可。数据、渲染软件、外部重建工具和训练资产都要分别查看条款。Forge3D 核心采用 Apache-2.0 或 MIT，部分 Pro 功能需要商业许可。

07

使用边界：画面、精度与速度分别验证

清晰纹理，不等于准确几何

影像像素、DEM 网格间距、点密度和测量误差各有含义。视觉真实感不能证明尺寸、位置与高程达到工程精度。

支持 4K 输出，不等于实时 4K

分块输出控制显存，不能直接推导帧率。飞行视频可以由逐帧渲染后合成；速度须结合硬件、场景、采样与渲染模式测试。

按需加载，仍有容量边界

分页有固定的驻留池。融合文档中的精确模式若单视角所需页面超过池容量，会报预算错误；渐进模式则需关注加载过程中的结果状态。

DEM 是高度场，形状表达有限

一个水平位置存一个高度，不能完整表达洞穴、悬挑与垂直多层结构。建筑立面和复杂局部需要其他几何或捕获资产。

实拍外观可能保留原光照

3DGS 资产中的采集光照可能已经体现在颜色里，重新照明时可能带来明暗或色彩偏差。显示效果与材质恢复需要分开评估。

公开不代表最新，也不保证完整

不同数据可能来自不同年份，树木、建筑和道路会变化；水面、阴影、云和遮挡也会留下缺口。需要保存每份输入的来源与日期。

下一步验证：先做一个小范围场景

  1. 选一块有明确数据来源的区域，先使用 DEM 与正射影像。
  2. 核对坐标、基准、单位、区域边界和许可，保存来源清单。
  3. 输出低分辨率测试帧，检查地形形态、贴图与相机方向。
  4. 加入点云；有需要时再补外部重建的 3DGS，检查配准和阴影。
  5. 记录硬件、版本、采样、耗时和峰值内存，再提高输出尺寸。
  6. 最后生成多视角序列，检查闪烁、分页状态与可用的细节范围。
