# 变更审查交付检查清单

本页原创示例，用于核对审查结果。按项目实际情况调整。

- [ ] 用户要求的修改范围已明确，diff 与该范围一致。
- [ ] 项目规则、源码与相关测试已按需要读取。
- [ ] 行为变化对应实际修改，未加入无依据推测。
- [ ] 每条发现提供具体文件位置、触发条件、影响与依据。
- [ ] 已执行的检查有真实命令、结果和覆盖范围。
- [ ] 没有执行的检查说明原因与后续验证方式。
- [ ] 结论区分运行验证、源码推理与仍需确认的部分。
- [ ] 下一步建议对应具体问题或证据缺口。

流程到达交付环节，不单独证明代码行为正确。检查记录应能够回到原始输入和运行证据。
