# 项目约定示例

这是原创学习示例。按项目事实补齐后，把必要信息合并进已有 CLAUDE.md。

## 项目结构

- 主要源码目录：填写真实路径及职责。
- 测试目录：填写真实路径及运行方式。
- 构建输出与生成文件：说明哪些文件通过工具生成。

## 构建与检查

- 构建命令：填写当前实际命令及必要前置条件。
- 测试命令：填写当前实际命令，注明覆盖范围。
- 其他检查：填写项目已有的类型检查或静态检查命令。
- 需要网络、服务或测试数据时，说明依赖与取得方式。

## 审查与交付

- 先明确修改范围，再读取差异和相关代码。
- 输出行为变化、具体发现、验证证据与未验证项。
- 每条发现关联到实际文件位置，并说明触发条件与影响。
- 未执行命令时记录原因；文字推理与运行验证分别说明。
- 项目结构或命令改变后，更新这份约定。

项目指令是模型上下文，具体工具权限应在运行时配置中核对。
