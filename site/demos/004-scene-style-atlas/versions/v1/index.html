02 / STYLE SYSTEM

把风格，沉淀成五层规则。

从一次好看的画面，
走向可以持续制作的资产体系。

01

场景组织

先让它像一个地方。

道路如何连接聚落，建筑与树群怎样分布，哪里拥挤、哪里留白。

可沉淀资产

布局样板 · 道路与地块模块 · 植被组合 · 生活痕迹

02

模型语言

形体决定识别与亲近感。

统一人物、车辆和建筑的比例，规定轮廓特点与中景下的细节密度。

可沉淀资产

比例规范 · 轮廓范例 · 建筑组件 · 完好与受损状态

03

材质与光影

让不同模型属于同一个世界。

控制色谱、粗糙度、阴影层次与环境光，让重点可读、背景有气氛。

可沉淀资产

材质库 · 配色规则 · 光照预设 · 表面磨损规范

04

动态反馈

动起来，才知道有没有重量。

协调移动速度、动作节奏、烟尘尺度和碎片运动，让事件留下可见后果。

可沉淀资产

动作节奏 · 粒子效果 · 破坏表现 · 音画配合规则

05

镜头与尺度

决定玩家如何读这个世界。

统一观察角度与画面范围，检查中景里的层次、遮挡与单位辨识。

可沉淀资产

镜头预设 · 构图样板 · 可读性截图 · 细节分级

03 / GAME EXTENSIONS

从美术资产，延伸游戏体验。

以下是设计假设，
需要通过玩法原型继续验证。

假设 A地形 / 遮挡 / 重量

小队战术

围绕街角、院落与林带组织行动，让清晰的模型轮廓和冲击反馈服务于战场判断。

复用基础

聚落场景、人物与车辆、损坏状态

验证重点

中景能否看清位置、行动与反馈

假设 B探索 / 痕迹 / 气氛

废土探索

把建筑、道路和残骸转为探索线索，用磨损、空地与局部光源形成环境叙事。

复用基础

街区模块、磨损材质、废弃物件

验证重点

环境能否引导路线并传达故事

假设 C建设 / 日常 / 变化

营地建设

让同一套建筑和地景承担搭建、修复与日常活动，通过场景变化表现营地的成长。

复用基础

建筑组件、自然地景、生活细节

验证重点

建设前后是否带来可见的成长感
