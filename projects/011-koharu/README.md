## 项目定位与能力

Koharu 以 Rust 为核心，面向漫画图片中的文字和版面处理，将检测与分割、文字识别、语言翻译、背景修复和文字排版组合成可编辑的桌面工作流。典型流程是识别文字与气泡、提取原文、生成译文、擦除原字并修补背景，再将译文排回漫画页面。

它还提供人工校对、画布与图层编辑、多页批量处理，以及 PNG 和分层 PSD 导出。翻译可选择本地模型或云端服务。以上能力均围绕漫画翻译与页面制作场景组织。
