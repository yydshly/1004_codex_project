## 项目是什么

这是一个在浏览器里游玩的红警游戏项目，包含建造基地、采矿、生产部队、战斗和联机对战等即时战略玩法。仓库自称“网页红警一键部署包 / Chrono Divide assets”，主要提供相关网页客户端、游戏资源和部署文件。玩家控制台 API 是游戏附带的脚本操作能力。

该项目属于第三方项目。相关的 [Chrono Divide](https://chronodivide.com/) 明确自称爱好者复刻，与 EA 无隶属关系。记录“网页版红警游戏”这一产品定位，不认定它已经完整还原原版全部功能，也未验证完整开发源码的公开程度。
