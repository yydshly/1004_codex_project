01

一条从实拍到三维资产的完整链路

它的核心价值是：让你用自己的照片或绕拍视频，训练一个能从新角度观察的三维外观，并进一步获得可交给其它工具使用的资产。

Spirula Studio 是一个自包含的 C++ 桌面与命令行应用。上游主流程覆盖视频抽帧、AI 掩膜、SfM 相机重建、三维高斯训练、曝光与白平衡修正、查看编辑，以及高斯、网格和渲染结果导出。已有 COLMAP、Nerfstudio 或 Metashape 相机数据也可以接入。

Vulkan 是上游推荐的跨厂商后端，面向 NVIDIA、AMD、Intel 与 Apple GPU；另提供面向 NVIDIA 的 CUDA 后端。量化训练与 GPU 内存优化是其工程重点。这些是官方披露与源码研究结论，本页没有给出本机速度、画质或设备兼容性承诺。

依据：官方 README 与后端说明 ↗。原生抽帧、SfM 和 AI 掩膜列在 Vulkan 构建路径；两种后端均提供训练与网格功能。

02

准备什么，得到什么

INPUT / 输入

同一场景的多角度观察

  • 多张照片或绕拍视频：主要面向静态物体与场景，相邻视角应有重叠，并让相机位置发生变化。
  • 相机信息：由内置 SfM 求解，或导入已有重建数据。稀疏点云可用于初始化，也可在有相机信息时随机初始化。
  • 可选辅助：主体 / 干扰物掩膜、深度与法线，帮助选择训练区域和约束几何。
OUTPUT / 输出

可保存、可查看的三维结果

  • 三维高斯资产：保存位置、形状、透明度和外观参数，用兼容查看器观察新视角。
  • 带纹理网格：经过表面提取与纹理处理，可导出 PLY、OBJ、glTF、GLB、STL 等网格格式；颜色与纹理承载方式随格式不同，实际质量需要检查。
  • 新视角内容：导出渲染图片与镜头视频，用于展示、讲解、留档或宣传内容。

拍摄决定可恢复的信息。绕到侧面和背面、控制模糊、尽量保持场景与光照稳定。单张照片看不到的结构，不能依靠多视图重建自动变成有事实依据的背面。

依据：数据集与相机说明 ↗；拍摄建议由多视图几何条件推导。

03

Gaussian 不是一个现成的大模型

可以把一个 Gaussian 理解为一个中心最浓、向外逐渐变淡的椭球形贡献范围。它是数学函数，不是真的烟雾、实体小球或普通网格。场景由许多这样的元素组成，每个元素具有中心位置、三轴尺度、旋转、不透明度和颜色参数。

G(x) = exp[ −½ (x − μ)ᵀ Σ⁻¹ (x − μ) ]

μ 决定中心，Σ 决定椭球的形状与方向。渲染时，把三维椭球投影成屏幕上的二维椭圆，按深度顺序叠加透明颜色。球谐函数（SH）让颜色能随观察方向变化，帮助拟合视角相关外观。

训练会移动、拉伸、旋转和调整这些元素，还会按需要增加或移除元素，使渲染图更接近真实照片。高斯集合因此既包含空间信息，也承担外观拟合；看起来真实，并不自动等于精密、完整的实体几何。

SCENE OPTIMIZATION / 逐场景训练

为这一组照片优化一份资产

Spirula 的核心循环是“渲染 → 与输入图像比较 → 更新高斯参数”。换一套拍摄对象，通常需要为新场景重新求解与优化。这里的“训练”不是在训练一个能够理解所有物体的通用语言模型。

MODEL INFERENCE / 已训练模型推理

共享网络根据输入预测或生成

QuerySplat 用已训练网络从图像预测高斯，且提供可选测试时优化；TRELLIS.2 以图片为条件生成三维网格。它们依赖预先学到的知识。推理与逐场景优化可以组合，但输入、输出和结果依据各不相同。

04

底层原理：四个环节相互配合

  1. 把采集素材变成训练视图

    视频抽帧、照片整理，按需用 AI 掩膜保留主体或排除干扰物。鱼眼与全景输入使用相应相机模型；掩膜解决“训练哪些区域”，不直接生成三维形状。

    得到：图像，以及可选掩膜

  2. 求解相机与空间关系

    SfM 检测并匹配跨图特征，再通过三角测量和束调整求解相机位置、方向及稀疏空间点。已有相机数据可复用；这一步建立后续渲染的视角依据。

    得到：相机内外参与初始化依据

  3. 用图像误差优化三维高斯

    初始化高斯，使用可微渲染生成训练视角，与照片计算误差并反向更新位置、尺度、旋转、透明度和 SH 颜色。配合密度控制、几何约束和曝光修正，逐步拟合这一个场景。

    得到：能合成新视角的高斯表示

  4. 清理、提取和导出资产

    检查漂浮物、轮廓与未覆盖区域，进行清理编辑，保存高斯。进一步提取表面与纹理得到 mesh，或沿相机路径渲染图片和视频；不同输出需要各自验收。

    得到：高斯 / 带纹理网格 / 渲染内容

Spirula 在原始 3DGS 之外加入训练策略、内存优化、相机支持和资产处理。实现入口见 架构说明 ↗ 与 训练配置 ↗。

05

适合用在哪里，怎样扩展

OBJECTS / 物体

商品、收藏与展品

鞋子、工艺品、雕塑等静态物体的环绕展示与视觉留档。后续可增加细节热点、尺寸说明、故事标签和商品链接。

SPACES / 空间

门店、展厅与房间

从室内外实拍构建可观察的空间外观。后续可加入镜头路线、房间切换和解说；自由行走、碰撞和导航需要额外实现。

CONTENT / 内容

镜头创作与现场记录

利用新视角图片、漫游视频表达现场。适合展览留档、工程视觉记录和素材制作；精确测量用途仍需标定与独立验收。

对我们现有项目的意义

此前 Splat.js 鞋子实测验证了“绕拍视频 → 高斯资产 → 网页交互展示”的具体闭环。Spirula 可作为另一种原生训练与网格提取路线，再把导出资产交给兼容展示工具。选择工具前应先明确需求：拍摄真实对象进行重建，或用图生三维模型生成新的物体。

Spirula 已有本地 GUI Batch 训练与网格处理队列。在此基础上，可以进一步开发采集管理、跨机器 / 云调度、资产版本、业务任务编排、热点注释和质量检查。这些扩展需要自己的产品与系统实现，不能仅凭本地批处理入口视为已经完成。

优先选择一个小而完整的验证对象。沿用鞋子素材，对照原视频、不同视角、高斯与 mesh 输出，检查遗漏、轮廓和纹理，再决定是否迁移整个工作流。后端快慢与画质优劣应通过同数据、同条件实测判断。

07

技术边界与证据状态

静态场景优先

视频在主流程中提供多个采集视角。高斯核心参数没有时序形变表达，不能把视频输入直接理解为动态人物或 4D 动作重建。路人等干扰可通过掩膜处理，具体效果待验证。

拍不到的位置仍有不确定性

观察不足、弱纹理、强反光或模糊可能影响相机求解与拟合。离拍摄范围很远的新视角也可能出现空洞、漂浮物与拉伸伪影，需实际转动检查。

网格和真实尺寸要分别检查

高斯能拟合照片外观，但 mesh 输出不自动保证闭合、拓扑干净或 CAD 级精度。项目可利用合适的遥测信息辅助恢复尺度与方向，具体素材是否可用仍需验证。

视角颜色与更换灯光有区别

SH 拟合颜色随视角的变化。曝光校正也不等于分离物理材质、光源与阴影；原始高斯外观不能据此承诺任意换灯、布料模拟或局部毛发编辑。
