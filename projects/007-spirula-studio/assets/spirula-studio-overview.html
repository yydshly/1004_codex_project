02高斯究竟是什么？

中心强、边缘平滑减弱的数学函数。
柔边椭球是影响范围，不是实体烟雾。

G(x) = exp[−½ (x−μ)ᵀ Σ⁻¹ (x−μ)]

位置 · 大小 · 方向；颜色与透明度另存。
投影成椭圆，按深度透明混合成画面。

03渲染 → 比较 → 更新，反复拟合

相机先定位，再从稀疏点或随机点初始化高斯。

① 渲染视角从拍摄位置
生成训练图
② 计算误差与实拍照片比较
L1 / SSIM 等
③ 梯度更新位置、形状、外观
拆分 / 重定位
反复迭代，逐渐接近原照片

训练的是当前场景的一份资产。
预训练模型可辅助掩膜、匹配、深度与法线。

04GPU 与网格，负责什么？

Vulkan / CUDA：加速与省显存

量化训练、融合核函数、显存复用。
Vulkan：NVIDIA / AMD / Intel / Apple
CUDA：NVIDIA；容量与速度需实测。

Mesh：从占据场提取三角面

保留高斯 7 点 → Delaunay 四面体
默认阈值 0.5 → marching tetrahedra
清理表面 → 顶点色 / UV 纹理

主路径不是 TSDF；同为 PLY，
高斯、点云与网格字段仍不同。

意义与价值

把一次拍摄变成
可交互、可保存、
可复用的三维资产。

串起数据准备、重建、编辑与交付；
让多种显卡参与三维高斯训练。

实拍重建、模型生成、
资产编辑与渲染，是不同分工。

使用边界：拍摄覆盖与相机定位决定质量；逼真外观不保证精密尺寸、完整表面或制造可用。

动态、骨骼与物理重光照需要额外能力；没有实拍约束的背面仍有不确定性。
