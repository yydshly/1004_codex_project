## 人物为什么会拉开整幅画面的差距

人物同时提供尺度参照、生活感和风格线索。在建筑已经细化的场景里，简化人物会更明显地暴露比例与制作层次的差异。旧 V2 人物高度约 1.1 个场景单位，与门、屋檐和车辆比较时偏小；手臂接近直杆，肩、腰、髋和四肢的连接不足，服饰与姿势也较难辨认。

| 可见差距 | 对整体画面的影响 | 本轮处理方向 |
| --- | --- | --- |
| 人物与门、车辆的尺度关系偏小 | 场景尺度缺少稳定参照，人物更像附加的小标记 | 将细化人物按约 1.72 的身高组织，并检查与环境的相对关系 |
| 头、肩、腰、髋的关系简单 | 即使增加面数，也容易延续玩具或积木感 | 采用约 7–7.5 头身的设计比例，建立连贯的躯干与关节轮廓 |
| 衣物接近人体表面的一层颜色 | 衣服、皮肤和装备读成同一种体块 | 为服饰、背包、帽和靴加入可见体积，组织袖口、裤腿和装备层次 |
| 手臂直、姿态一致 | 人物缺少行动意图，场景的使用感不足 | 区分站立、行走、观察姿势，协调肩肘与髋膝的弯曲 |
| 行走只表现为位置移动 | 脚步与身体缺少关联，动作容易像漂移 | 加入步态相位、手脚配合和重心起伏，继续观察脚底与地面的关系 |
| 人物细节在中景难以看清 | 无法判断改进来自造型、配色还是镜头放大 | 增加独立人物近景，并允许回到主场景聚焦同一人物模块 |

上述比例是本轮的制作设定；生活感和风格一致性是设计判断。它们不等同于人体测量、真实玩家偏好或正式动画质量已经验证。

## 本轮的比较方式

当前 `detail-study` 页面继续作为最新研究入口，增加人物专项：

- **基础人物／细化人物：** 在相同观察条件下比较轮廓、比例、服饰与姿态。基础人物是当前对照基线；完整旧实现仍应从 V2 留存入口回看。
- **侦察兵／居民：** 比较帽、背包、衣物和靴等不同角色线索；同时检查不同装束是否遵守同一模型语言。
- **站立／行走／观察：** 查看肩肘、髋膝的连接与动作意图；暂停后可以检查单帧姿势。
- **人物近景与主场景聚焦：** 两处使用同一个人物模块，近景用于看制作层次，中景用于判断尺度、辨识和风格融合。
- **保存画面：** 留存当前实时画面和对应条件，供后续比较。

新增部分仍使用原创程序几何与程序动作。面部只提供简要结构，不作为精细脸部、表情或口型制作的完成结果；步态用于观察动作关系，不宣称真实物理步态。

## 回顾与验收关注点

推荐先在自然写实风格下固定镜头与光向，查看基础人物和细化人物的站立轮廓；接着比较居民与侦察兵；再查看行走和观察姿势。最后回到主场景，检查人物相对门、墙、车辆和道路的比例，并切换另外两种风格。

| 检查范围 | 应留下的证据 | 结论边界 |
| --- | --- | --- |
| 人物阶段与角色切换 | 固定镜头下的基础、细化及两种角色实际截图 | 切换可用不等于造型已经达到目标 |
| 身体与服饰轮廓 | 肩腰髋、肘膝、帽、靴与背包的近景，以及同一模型的中景 | 近景细节可见不等于中景仍有收益 |
| 姿态与暂停 | 站立、行走、观察的画面；暂停与恢复的实际操作记录 | 程序动作不等于正式绑定、动作捕捉或真实物理 |
| 环境尺度 | 人物与门、石墙、车辆的同框画面 | 设计比例不等于已逐项测量场景全部对象 |
| 三种风格 | 相同人物在配色、服饰和光影条件下的对照 | 风格切换不证明玩家偏好 |
| 保存与响应布局 | 实际 PNG 预览、桌面和手机页面截图 | PNG 数据有效不等于操作系统下载完成；单次检查不构成性能测试 |

浏览器实测与截图以项目 [verification.md](../verification.md) 的 V3 记录为准。本文件给出制作依据、比较方法和证据要求，不单独宣称所有操作已经检查通过。新截图使用 `assets/v3-*` 命名；保留 `assets/v1-*`、`assets/v2-*` 原始证据。

本轮已留存同机位[基础人物](../assets/v3-character-baseline.png)与[细化人物](../assets/v3-character-refined.png)、[人物与建筑同框](../assets/v3-scene-people.png)，以及[桌面人物页](../assets/v3-page-desktop.jpg)和[手机人物画布](../assets/v3-page-mobile-character.jpg)。近景对照采用侦察兵、站立、自然风格与暂停动作；两幅人物图均为 718 × 660，直接来自实时渲染。实际操作范围与仍未验证的内容见项目 V3 检查表。

## 完成后仍需继续解决的差距

人物专项改善的是尺度、轮廓和动作关系。程序几何仍需要检查关节转折、服饰穿插、脚底滑动、面部简化和材质均匀等问题。AI 概念图中的人物可以在静态画面中同时表现细致服饰、自然姿势与光影；当前实时模型的质量必须由实际渲染和操作证明，不能直接引用概念图作为已实现效果。

## V4 后续方向（尚未实施）

V2 当时把正式资产研究写为 V3 计划。本轮依据用户对人物的反馈，先开展人物专项；原来的正式模型与 PBR 方向顺延为 V4。以下仍是计划，不属于本轮已经实现的内容：

1. 制作有可编辑源文件的正式人物与场景模型，统一单位、材质槽、锚点和导出规则，再接入 GLB。
2. 为人物制作正式骨骼与蒙皮，调整肩、肘、髋、膝的变形，完善站立、行走和观察动作及过渡。
3. 制作并记录 base color、normal、roughness 等 PBR 材质来源，统一衣物、皮肤、皮革与金属的表面反应。
4. 继续完善自然植被、道路和接触关系；在固定中景中评价人物与环境共同形成的风格。
5. 在指定设备和分辨率下记录对象规模与运行成本，再决定人物细节层级和场景人数。

后续继续保留基础与细化样板、固定条件截图及当轮检查记录，让每次提升和剩余问题可以回查。
