## 本轮起点

V1 已整理三种场景、三种风格，以及镜头、细节、光照和动态的比较方法。它能表达场景布局和色彩方向，但实时模型仍主要由简化体块组成：建筑比较整齐，树冠有球体感，表面依赖颜色，道路和道具缺少磨损与使用痕迹。更换风格后，这种基础气质仍然存在。

用户指出，实时演示没有达到展示图里类似的精度和风格效果，并要求：

> 保留已有的步骤 可以优化扩展继续 方便后期回顾

因此本轮保留 V1，另做同场景细化研究。目标是提高玩家能看到的整体美术完成度：轮廓更自然，材料更可辨，对象更像落在环境里，光影支持这些变化。增加面数只在它能改善这些可见结果时有价值。

## 差距如何拆解

| 可见差距 | 对玩家感受的影响 | 本轮改进方向 |
| --- | --- | --- |
| 建筑轮廓过于简单 | 容易读成摆放整齐的积木，缺少房屋的构造与重量 | 增加石砌分块、曲瓦屋顶、屋檐、窗框和百叶；用有意义的细部打破大平面 |
| 不同材料主要靠颜色区别 | 石头、木头、涂料容易显得像同一种表面 | 用原创程序纹理、凹凸和粗糙度变化区分材料；检查变化在中景是否仍可见 |
| 球形树冠与重复植被 | 自然环境显得人工、均匀，缺少生长方向 | 增加树干与分枝，使用叶卡组织树冠；改变轮廓与局部密度 |
| 道路边缘整齐、表面平整 | 缺少行走和车辆经过的感觉 | 增加轮痕、边缘碎石、裸土与草地过渡，让道路与地面接起来 |
| 车辆缺少辨识细部 | 能看出一个物体，却难感到它的功能、比例和重量 | 细化 utility 车辆的轮胎、轮毂、车窗、格栅和外部构件 |
| 墙脚和物件周围太干净 | 对象像浮在独立展示台上，场景不像被使用的地点 | 增加杂草、花草、墙脚生活道具和局部散落物；保留主通路与视觉留白 |
| 光影没有充分交代接触关系 | 模型细化后仍可能显得平、散或悬浮 | 比较光向与阴影，关注屋檐、车轮、墙脚和植被根部的接触感 |

这里的“玩家感受”是美术设计假设。当前比较可以提供可见差异的证据，偏好、代入感和辨识速度仍需要真实用户观察。

## V2 的比较方式

V2 使用独立页面，把同一场景分成两个制作阶段：

- **基础体块：** 用于查看细化前的轮廓、配色与空间关系。它是 V2 同构图中的比较基线；需要回看 V1 完整实现时，打开已保留的 V1 页面。
- **细化样板：** 在相同主要布局与镜头下，查看建筑、材质、植被、道路、车辆和生活细部的变化。

两阶段沿用自然写实、温暖微缩、荒凉废土三个方向。镜头、光向、暂停和快照用来组织对照，避免把不同观察条件误认为制作提升。

建议按以下顺序回顾：先固定自然写实、中景和光向，切换两个阶段；再靠近查看屋顶、窗框、车轮和墙脚；随后回到中景，确认细节没有淹没通路与主体；最后分别比较温暖微缩和荒凉废土，观察材料与植被是否共同支持风格，而非只改变全局颜色。

## 验收关注点

本节定义比较方法，不代替最终浏览器检查报告。每项结论应附对应阶段、风格、镜头和光向的实际截图。

| 检查范围 | 应观察的结果 | 不应据此推导的结论 |
| --- | --- | --- |
| 同构图阶段切换 | 主体位置与相对比例可比较，细化对象和对应基线能关联 | 所有几何位置都已精密测量 |
| 建筑与车辆 | 屋檐、曲瓦、窗框、车轮等在近端可辨；回到中景仍保留清楚的主体轮廓 | 面数越多就越接近目标 |
| 材料 | 石、木、瓦、土和金属的明暗与表面反应有区别 | 已具有完整的扫描级 PBR 资产 |
| 植被与地面 | 树冠轮廓较自然，道路边缘与墙脚有过渡；主通路仍可读 | 已完成自然植被的正式制作 |
| 三种风格 | 同一细化样板在颜色、材料、植被与光影上呈现可见差异 | 某种风格已被玩家验证为更好 |
| 镜头、光向、暂停和快照 | 控件作用可见，截图来自当前实时场景并记录比较条件 | 正式产品的性能和长时间稳定性已经验证 |
| 桌面与手机 | 操作和说明可阅读，视口缩小时场景仍可观察 | 所有设备和浏览器均已覆盖 |

实际运行、交互、截图与局限应记录在项目 [verification.md](../verification.md) 的 V2 部分。若某项只完成制作，记录为实现；若经过操作或视觉检查，记录具体观察；若还需固定设备测量，不写成性能通过。

### 本轮实际留存

浏览器保存了固定机位、自然写实、镜头 22、光向 25°、暂停动态的 [基础体块](../assets/v2-baseline-natural.png) 与 [细化样板](../assets/v2-scene-cover.png)。第二轮网页并排显示两幅原始 PNG；它们均来自实时渲染，不是 AI 概念图。第一轮完整源码及原始截图继续单独保留。

## 与展示图仍需区分的地方

AI 概念图把造型、材质、布景和光影一并表达为静态画面。V2 是原创程序场景的进一步细化，能够逐层比较制作带来的变化，但不应把它描述成已达到概念图效果，或已复现 Defilade 的正式美术质量。

当前仍应特别检查树叶的剪影和层次、曲瓦在中景的可读性、材质重复、接触阴影，以及生活细部是否分布自然。图片中看起来合理的细节，也需要在转动镜头、切换光向和手机视口下继续成立。

## V3 后续方向（尚未实施）

V3 可从已经认可的一块中景出发，逐项替换资产。以下是后续计划，不属于 V2 已完成内容：

1. **制作一套正式模型。** 为石屋、瓦顶、石墙、树木和车辆制作可编辑源文件，统一单位、比例、锚点和材质槽，再导出 GLB。保留对应的程序样板，便于判断替换收益。
2. **制作真实 PBR 材质。** 使用有来源记录的 base color、normal、roughness 等贴图，统一纹理尺度；先解决材料分工与表面层次，再提高分辨率。
3. **继续改善自然树木。** 制作分枝层次、叶簇方向与透光感，检查多棵树的差异和中景遮挡；在目标设备上决定细节层级与实例预算。
4. **完善地表与接触关系。** 道路、裸土、草地和墙脚使用统一的过渡规则，让物件与环境一起成立。
5. **固定对照场景与测量条件。** 保留相同构图和相机，记录实时截图、设备、分辨率和对象规模；分别评价视觉收益与运行成本。

后续仍以“这一块中景给人的整体感觉是否接近目标”为主线。先把一个场景做稳，再扩展同风格的建筑、植被、道具与不同地点。
