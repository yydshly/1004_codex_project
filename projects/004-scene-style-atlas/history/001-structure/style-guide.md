# 004 · 可复用风格规范

[项目摘要](README.md) · [研究笔记](notes.md)

本规范分为“当前演示参数”和“后续模型建议”。它是本项目的原创设计记录，不是 Defilade 官方美术规范。

## 当前演示参数

| 项目 | 参数 / 约定 | 比较时的作用 |
| --- | --- | --- |
| 场景 | `village` / `industry` / `town` | 乡村道路 / 工业院落 / 城镇街区 |
| 风格 | `natural` / `miniature` / `wasteland` | 自然写实 / 温暖微缩 / 荒凉废土 |
| 地面展示范围 | 约 44 × 36 场景单位 | 在中景容纳建筑群、通路和植被 |
| 小型角色高度 | 约 1.3 场景单位 | 作为轮廓和相对尺度的参照 |
| 常规建筑高度 | 约 3–6 场景单位 | 保留道路与建筑之间的空间关系 |
| 树木高度 | 约 4–7 场景单位 | 形成自然边界与遮挡层次 |
| 镜头跨度 | `camera-scale`：16–40，默认 26 | 正交镜头纵向可见跨度；值越大越远 |
| 细节 | `detail-level`：0 / 1 / 2，默认 2 | 控制小道具与细部可见程度 |
| 光照强度 | `light-strength`：0.7–1.8，默认 1 | 检查轮廓、阴影和材料分工 |

这些是教学原型的场景单位与相对比例，不是精准物理尺度。切换风格时主要对象布局和相对大小保持一致；荒凉废土的稀疏植被与损伤表现属于有意的状态差异。

## 镜头与构图建议

后续模型统一在正交斜俯视镜头下验收。推荐相机对水平面向下 35°–50°、水平朝向偏离主道路 30°–45°；这些角度是后续建议，不是当前控件实参。

- 用镜头跨度 26 检查默认中景，再用 16 和 40 检查近端细节与远端可读性。
- 前景允许一两处较大轮廓，中景保留主道路和活动区，后景用建筑或植被形成边界。
- 主通路应连续可见；关键活动区不被屋顶或树冠完全遮住。允许局部遮挡，但通过体块、阴影与留白交代空间。
- 光照与视觉重点应有明确方向。细节不能让所有区域都成为焦点。

## 模块、比例与锚点

当前 1.3 高的小型角色用于相对尺度检查。后续正式模型推荐以米为源文件单位，并在导入时设置统一换算比例，不混用“1 个场景单位”和“1 米”。

| 模块 | 后续建议 | 验收关注点 |
| --- | --- | --- |
| 建筑 | 地面锚点居中，主体／屋顶／开口／附属物分层；常见平面模块采用 4、6、8 米尺寸系列 | 主体轮廓在中景可读，门窗比例一致，屋顶不过度遮住通路 |
| 道路与地面 | 路面、边缘、裸土、植被区域独立分组；路径节点按统一网格连接 | 连接不出现高差缝隙；路面与背景有可辨差异 |
| 墙与围栏 | 建议 2 米为基本连接段，端点对齐，转角独立模块 | 同材质不同段落无明显断色；端头能接建筑与地形 |
| 植被 | 树干／树冠分开，至少准备三种轮廓与三种高度 | 轮廓有变化，避免等距复制；密度变化仍保留场景路径 |
| 道具 | 箱体、设备、车辆与残骸按轮廓类别组织，底部锚点稳定 | 相同镜头下仍能分辨功能类别，不依赖文字或细碎纹理 |
| 状态件 | 完整／受损／残骸沿用同一位置、朝向和识别特征 | 变化能读懂，切换不发生整体位置跳变 |

## 材质与色彩建议

以下数值是后续材质制作的起始范围，不是对当前渲染器实参的反向测量。以同一镜头、同一光强比较，先确认材料分工，再微调颜色。

| 风格 | 色彩与材料规则 | 粗糙度起始建议 | 金属度起始建议 |
| --- | --- | --- | --- |
| 自然写实 | 土、石、木、涂料分区；绿色以明度和冷暖区分，屋顶和墙面保留材料差异 | 非金属 0.70–0.95；裸金属 0.40–0.75 | 非金属 0；裸金属 0.65–1.00 |
| 温暖微缩 | 暖中性色组织建筑，植物保留柔和色差；简化污渍与裂缝，强化体块 | 0.75–0.95 | 多数表面 0；必要裸金属单独设定 |
| 荒凉废土 | 灰土、锈色和低饱和植被形成背景；损伤区改变明度与形状，保留少量辨识色 | 0.75–1.00；裸金属区域独立调整 | 灰土／锈层 0；露出的金属 0.65–1.00 |

- “自然写实”是本项目的方向名，当前几何仍有明显简化，不作为照片级效果承诺。
- 避免靠整体滤镜制造三种风格。天空、雾、光照、材料分工与局部状态需要共同支持方向。
- 小纹理以中景可见度为依据；大块明暗、体块和接触阴影优先于密集噪声。
- 金属度描述材料类型，不用少量金属度模拟所有表面的光泽。灰尘、锈层和涂料与裸金属分别处理。

## 动态与变化建议

以下是后续可复用动效的建议区间。当前演示只用于说明这些方向，具体实现参数以源码与检查记录为准。

| 动效 | 建议参数 | 玩家体感目标 |
| --- | --- | --- |
| 环境摆动 | 2–4 秒周期，树冠位移不超过自身宽度的 1%–3% | 场景有生命感，静态体块仍稳定可读 |
| 人物移动 | 以角色高度为基准，每秒约 1–2 个身高；起停 0.15–0.30 秒 | 小型角色有重量和方向，不像随机漂移 |
| 冲击反馈 | 起势 0.05–0.12 秒，主体反馈 0.20–0.45 秒，尘土或余波 0.6–1.5 秒 | 来源、受影响对象与结果能够关联 |
| 镜头震动 | 可视跨度的 0.2%–0.6%，衰减 0.12–0.25 秒 | 提供冲击感，同时保留空间定位 |
| 破坏状态 | 完整 → 局部损伤 → 残骸；主要碎块保持原物体的材料与局部轮廓 | 能识别被改变的对象，避免只有通用粒子 |
| 修复状态 | 从残骸或缺损向完整过渡，保留锚点和占地范围 | 变化可比较，可用于游戏或状态展示 |

持续动态需要支持暂停，便于检查静态模型和拍摄对照图。动效强度应服务于场景读懂程度；体感结论仍需要真实用户观察。

## 后续模型交付建议

推荐使用 GLB 作为可预览交付格式，并保留可编辑源文件。每个模块附一行清单：名称、源单位、实际尺寸、锚点、材质槽、状态、细节层级和出处。

- 节点命名示例：`town_house_01_body`、`town_house_01_roof`、`town_house_01_damaged`。
- 同系列模型统一坐标、底部锚点和比例；导入后检查朝向、法线、负缩放和材质链接。
- LOD0 保留近端细部，LOD1 优先保留中景轮廓，LOD2 保留远端体块；面数预算在真实目标设备与实例数量确定后实测制定。
- 贴图建议从 512 / 1024 级别开始对照；是否需要更高分辨率由实际画面尺寸决定。纹理颜色空间按用途设置，避免把粗糙度图当颜色图。
- 每个新模块至少截图检查：默认镜头 26、近端 16、远端 40，以及三个风格预设。
- 完整、损伤和残骸状态必须具有相同来源记录；不得把概念图当成已制作模型的验收图。
