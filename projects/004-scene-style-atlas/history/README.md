## 回顾时先看什么

1. **当时要回答的问题。** V1 回答“这套场景与风格框架是否可比较”；V2 回答“细化哪些可见层次，才能缓解积木感并形成材质和环境感”；V3 回答“人物的比例、服饰轮廓与动作如何支持场景尺度和生活感”。
2. **实时画面与概念图的区别。** AI 概念图用于表达目标方向；只能用当前实时渲染图说明已经实现的效果。
3. **比较条件。** 优先固定场景、镜头、风格和光向，切换制作阶段；再单独改变某个条件，避免同时换构图和光照后误判模型改进。
4. **证据边界。** 操作可用、画面更丰富与真实玩家更喜欢是不同结论；没有实测的性能和玩家感受不写成已验证。
