## 项目定位

这里的“群组收集器”指整理 Telegram 群组及相关资源入口的导航清单。它收录群组、频道、机器人和开发工具的链接与简介，方便按类别查找；收集对象是资源入口，不是群聊记录或群文件。

## 后续用途与当前安排

后期需要查询 Telegram 相关资料、寻找交流社群、机器人或开发工具时，可重新查阅这个目录，再进入对应群组、频道或项目获取具体资料。

当前仅保存摘要、来源和参考用途，暂不研究。归档表示保留后续查询入口，不表示已完成技术研究。
